使用指南

1 选择平台

在上方选择你需要订阅的平台，找到对应的订阅源卡片。

2 输入用户ID

在输入框中填入目标用户的ID。各平台ID获取方式请参考卡片中的帮助链接。

3 复制链接

点击「复制链接」按钮获取RSS订阅地址，或点击「打开预览」直接在浏览器中查看。

4 添加到阅读器

将复制的RSS链接添加到你的RSS阅读器（如 Feedly、Inoreader、Folo 等）即可订阅。

环境变量配置

🔑 WEIBO_COOKIE

微博订阅需要配置Cookie。登录微博后从请求头中获取。

wrangler secret put WEIBO_COOKIE

🔑 DOUYIN_COOKIE

抖音订阅可能需要配置Cookie。登录抖音网页版后从请求头中获取。

wrangler secret put DOUYIN_COOKIE

ℹ️ API 接口

所有订阅源信息可通过API获取，方便程序化调用。

GET /api/feeds
